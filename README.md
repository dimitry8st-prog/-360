# ДИС Аналитик 360

**ДИС Аналитик 360** — это персональный AI-помощник для работы с данными. Он создан для предпринимателей, руководителей, маркетологов и всех, кому нужно быстро разобраться в таблице без сложных формул и программирования.

Просто загрузите файл и задайте вопрос обычными словами:

> «Покажи, какие товары продаются лучше всего, найди проблемные показатели и построй понятный график».

ДИС проверит данные, найдёт пропуски и дубликаты, рассчитает основные показатели, построит интерактивные графики и объяснит результат человеческим языком. Сначала пользователь получает короткий вывод, а при необходимости может открыть подробности и посмотреть, как выполнен расчёт.

## Что умеет ДИС

- анализировать CSV, Excel, JSON, PDF и изображения;
- находить пропуски, дубликаты и возможные проблемы в данных;
- работать в режимах бизнес-, финансового и маркетингового аналитика;
- строить столбчатые, линейные, круговые и другие графики;
- показывать графики прямо в браузере и сохранять их в PNG;
- сохранять историю анализов отдельно для каждого пользователя;
- объяснять использованные колонки, фильтры и способы расчёта;
- отображать ход обработки в реальном времени;
- вести журнал событий и ошибок без записи содержимого личных файлов.

## Зачем нужен проект

Обычная таблица показывает цифры, но не всегда помогает понять, **что произошло и на что обратить внимание**. ДИС превращает данные в понятный диалог: помогает увидеть тенденции, проверить гипотезу и подготовить материал для принятия решения.

AI не подменяет точные вычисления: основные показатели рассчитываются программно, а модель помогает понять запрос и объяснить результат. Важные выводы можно проверить через раздел **«Как рассчитано»**.

## Текущий статус

Собрана пробная версия проекта. Уже работают регистрация, личный кабинет, загрузка файлов, базовый анализ, интерактивные графики, WebSocket-статусы, история операций и админ-панель.

OpenAI, отправка писем и двухфакторная авторизация пока работают как безопасные заглушки и будут подключены перед развёртыванием рабочей версии.

## Техническая основа

- FastAPI и Uvicorn;
- PostgreSQL в Docker и SQLite для локальной демонстрации;
- Redis и Celery для фоновых задач;
- Plotly и Kaleido для графиков и экспорта PNG;
- WebSocket для статусов в реальном времени;
- Nginx и Docker Compose для круглосуточного запуска;
- структурированное логирование и диагностический журнал;
- срок хранения пользовательских файлов — 30 дней.

## Быстрый локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Демо-администратор создаётся из переменных `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

## Docker

```bash
cp .env.example .env
docker compose up --build -d
docker compose ps
curl -fsS http://127.0.0.1:8000/health
```

Контейнеры: `web`, `worker`, `db`, `redis`, `nginx`. Для рабочего развёртывания необходимо заменить значения `change-me`, настроить SMTP, домен и HTTPS.
