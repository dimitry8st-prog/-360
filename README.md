# ДИС Аналитик 360

**ДИС Аналитик 360** — это персональный AI-помощник для работы с данными. Он создан для предпринимателей, руководителей, маркетологов и всех, кому нужно быстро разобраться в таблице без сложных формул и программирования.

Просто загрузите файл и задайте вопрос обычными словами:

> «Покажи, какие товары продаются лучше всего, найди проблемные показатели и построй понятный график».

ДИС проверит таблицу: пропуски, дубликаты и основные показатели. Для PDF извлечёт текст и ключевые числа. Графики строятся интерактивно; PNG сохраняется, если доступен движок экспорта. Сначала пользователь получает короткий вывод, затем может открыть подробности и раздел **«Как рассчитано»**.

## Что умеет ДИС

- разбирать CSV, Excel, JSON, PDF; для изображений — метаданные (без OCR);
- находить пропуски и дубликаты **в таблицах**;
- работать в режимах бизнес-, финансового и маркетингового аналитика;
- строить **семь** типов графиков: bar, line, histogram, pie, scatter, box, heatmap;
- показывать графики в браузере; PNG — если Kaleido отработал;
- вести чат с активным файлом, сообщениями и экспортом диалога в Markdown;
- объяснять колонки и способ расчёта;
- показывать статус WebSocket-канала («подключено / канал работает»), не пошаговый прогресс анализа;
- вести журнал событий без записи содержимого личных файлов.

## Зачем нужен проект

Обычная таблица показывает цифры, но не всегда помогает понять, **что произошло и на что обратить внимание**. ДИС превращает данные в понятный диалог: помогает увидеть тенденции, проверить гипотезу и подготовить материал для принятия решения.

AI не подменяет точные вычисления: основные показатели рассчитываются программно, а модель помогает понять запрос и объяснить результат. Важные выводы можно проверить через раздел **«Как рассчитано»**.

## Текущий статус

Собрана пробная версия. Работают регистрация, кабинет, чат с активным файлом, загрузка, локальный анализ, интерактивные графики, статус WebSocket, журнал, экспорт Markdown и админ-панель. Список прошлых чатов на кабинете не выводится: новый чат открывается кнопкой, сообщения хранятся в базе.

Если `OPENAI_API_KEY` пуст, чат в демонстрационном режиме показывает локальные факты, кастомный промпт в модель не отправляется. С ключом подключается OpenAI. Письма, 2FA, OCR и AI-песочница не готовы.

Docker Compose в репозитории есть (web, worker, scheduler, db, redis, nginx); круглосуточный запуск на вашей машине отдельно не проверялся.

## Техническая основа

- FastAPI и Uvicorn;
- PostgreSQL в Docker и SQLite для локальной демонстрации;
- Redis и Celery для фоновых задач;
- Plotly и Kaleido для графиков (PNG при успешном экспорте);
- WebSocket для статуса канала, не для прогресса разбора файла;
- Nginx и Docker Compose для развёртывания (нужна проверка на Docker-хосте);
- структурированное логирование и диагностический журнал;
- срок хранения пользовательских файлов — 30 дней.

## Быстрый локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Демо-администратор создаётся из переменных `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

## Docker

```bash
cp .env.example .env
docker compose up --build -d
docker compose ps
curl -fsS http://127.0.0.1:8000/health
```

Контейнеры: `web`, `worker`, `scheduler`, `db`, `redis`, `nginx`. Планировщик ежедневно удаляет загруженные файлы старше срока `FILE_RETENTION_DAYS`. Для рабочего развёртывания необходимо заменить значения `change-me`, настроить домен, HTTPS, резервное копирование базы и внешний мониторинг.
